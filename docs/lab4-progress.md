## День 1 Базовое оформление

### Исходное состояние

До изменений рабочее дерево Git было чистым. В качестве визуального образца использован отчёт лабораторной работы 2 «Отчет_Reflex_Duel_.docx», найденный в Downloads. При сравнении обнаружены растянутые на всю ширину кнопки выбора очков, отсутствие рамок у белых карточек и незаданная палитра стандартных компонентов Material. Базовая тема DayNight при этом сочеталась с явно светлыми фонами и чёрными надписями.

### Выполненные изменения и их назначение

В colors.xml заданы светлый фон #F1F3F8, синий акцент #2D6BE5, основной текст #22272F и отдельный цвет поверхности surface. Цвета подобраны по изображениям макетов; точные исходные дизайн-токены в документе не приведены.

В themes.xml заданы цвета основных компонентов, поверхностей, текста и системных панелей. На этом этапе используется светлая тема Material3.Light.NoActionBar. Это позволяет избежать смешивания тёмных стандартных компонентов со светлыми карточками. Переключение темы будет реализовано во второй день. Ночное переопределение базовой темы удалено, чтобы оно не перекрывало общие настройки.

В неигровых экранах ссылки на чёрный цвет основного текста заменены на text_primary. Это позволяет отдельно менять цвет текста при добавлении тёмной схемы. Белый текст на акцентных кнопках сохранён.

В bg_card.xml добавлена рамка толщиной 1dp цвета divider_gray. Для белого фона карточек и контурных кнопок используется surface. Карточки истории, выбора режима и поля имён получают общий внешний вид.

На главном экране кнопкам 3, 5 и 7 заданы размеры 56 на 40dp вместо растягивания через layout_weight. У невыбранной кнопки подпись окрашивается в text_secondary, у выбранной остаётся белой. Полям имён явно задан основной цвет текста.

### Фрагменты исходного кода

Палитра в app/src/main/res/values/colors.xml:

```xml
<color name="screen_background">#F1F3F8</color>
<color name="blue_primary">#2D6BE5</color>
<color name="text_primary">#22272F</color>
<color name="surface">#FFFFFF</color>
```

Рамка карточки в app/src/main/res/drawable/bg_card.xml:

```xml
<solid android:color="@color/surface" />
<stroke android:width="1dp" android:color="@color/divider_gray" />
<corners android:radius="16dp" />
```

Цвет выбранной кнопки в MainActivity.kt:

```kotlin
chip.setTextColor(ContextCompat.getColor(this, if (selected) R.color.white else R.color.text_secondary))
```

## День 2 Переключение цветовой схемы

### Выбор и сохранение темы

В разделе «Внешний вид» строка «Тема» открывает диалог с тремя вариантами. В диалоге отмечена текущая тема. После выбора оформление обновляется сразу, а под строкой «Тема» появляется название выбранного варианта. Кнопка «Отмена» закрывает диалог без изменения настройки.

`AppPreferences` хранит настройку `theme` в `SharedPreferences` со значением `light`, `dark` или `system`. При первом запуске используется тема устройства. `ReflexDuelApp` считывает настройку до открытия первого экрана. Режим «Системная» применяет светлую или тёмную схему в зависимости от настройки Android.

Фрагмент обработчика выбора темы из `SettingsActivity.kt`:

```kotlin
.setSingleChoiceItems(labels, themes.indexOf(preferences.theme)) { dialog, index ->
    val theme = themes[index]
    preferences.theme = theme
    themeValue.setText(theme.label)
    dialog.dismiss()
    AppCompatDelegate.setDefaultNightMode(theme.nightMode)
}
```

### Оформление экранов и диалогов

Общая тема использует `Theme.Material3.DayNight.NoActionBar`. Светлая палитра остаётся в `values`, а тёмные цвета определены в `values-night`. Android подставляет нужные цвета фона, карточек, подписей и разделителей в существующую разметку. Значки используют цвета основного или вспомогательного текста. В тёмной схеме заголовки разделов и выделенные показатели получили более светлый синий акцент. Заливка основных кнопок и цвета фаз раунда остаются общими для обеих схем. Диалоги выбора темы, паузы и подтверждения очистки истории используют оформление Material.

Фрагмент тёмной палитры из `values-night/colors.xml`:

```xml
<color name="screen_background">#121620</color>
<color name="surface">#1E2531</color>
<color name="text_primary">#F2F4F8</color>
<color name="text_secondary">#B0BACB</color>
<color name="blue_accent">#8AB4FF</color>
```

### Поведение при смене оформления

Android может пересоздать экран при смене цветовой схемы. Чтобы не сбрасывать выбранный режим и число очков, эти значения сохраняются в состоянии соответствующих экранов. Игровой экран обрабатывает смену `uiMode` без пересоздания, чтобы не сбросить текущий раунд. Экран итогов записывает матч в историю при первом открытии, чтобы при пересоздании не появлялась повторная запись.
